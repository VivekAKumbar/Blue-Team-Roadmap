## 10.1 Resume 🛠️ PRACTICAL

**Format rules:**
- One page only
- ATS-optimized — no tables, no graphics, standard fonts
- Standard sections: Summary, Skills, Certifications, Experience, Projects, Education

**Keywords to include:**
- SIEM, Splunk, KQL, SPL
- Incident Response, Threat Detection
- MITRE ATT&CK, NIST, CIS Controls
- Wireshark, Sysmon, Wazuh
- Windows Event Logs, Log Analysis

- [ ] Resume written — one page
- [ ] Technical Skills section with all tool keywords
- [ ] Certifications listed (most relevant first)
- [ ] Projects section — home lab, CyderSec, CTF achievements
- [ ] All bullet points quantified
- [ ] Reviewed by someone in the field or r/cybersecurity

## 10.4 Interview Prep

### Foundational Questions 📖 THEORY

- [ ] Explain the CIA Triad with examples
- [ ] Difference between IDS and IPS
- [ ] Describe the TCP three-way handshake
- [ ] Difference between encryption and hashing
- [ ] Authentication vs Authorization
- [ ] What is Zero Trust
- [ ] Name 5 common ports and their services
- [ ] How does DNS resolution work
- [ ] Difference between TCP and UDP
- [ ] What is a VLAN and why does it matter

### Framework Questions 📖 THEORY

- [ ] Walk through NIST IR phases
- [ ] How do you use MITRE ATT&CK in daily work
- [ ] What is the Cyber Kill Chain
- [ ] True positive vs false positive vs false negative
- [ ] How would you reduce false positives in a SIEM
- [ ] What are IOCs vs TTPs

### Tools Questions 📖 THEORY

- [ ] Write a basic Splunk SPL query
- [ ] What is Sysmon and which Event IDs are most useful
- [ ] What are SIGMA rules
- [ ] Event ID for successful logon vs failed logon
- [ ] How to detect cleared Windows Event Logs
- [ ] Difference between EDR and antivirus

### Scenario Questions 🛠️ PRACTICAL

**Scenario 1 — Phishing Investigation**
- [ ] Headers → URLs → sandbox → IOCs → SIEM → containment

**Scenario 2 — Brute Force Detection**
- [ ] Verify alert → IP reputation → successful login check → block → document

**Scenario 3 — Suspicious Process (Macro → PowerShell)**
- [ ] Identify parent process → check command line → isolate → trace email → ATT&CK mapping

**Scenario 4 — Lateral Movement**
- [ ] Baseline check → auth type → PsExec check → disable account → check all targets

**Scenario 5 — Ransomware Response**
- [ ] Isolate → identify patient zero → determine strain → check backups → identify entry vector

**Scenario 6 — Insider Threat**
- [ ] Verify alert → baseline → HR check → preserve evidence → escalate

### Behavioral Questions 📖 THEORY

- [ ] How do you stay current with cybersecurity news
- [ ] Describe a time you had to learn something quickly
- [ ] How do you prioritize when multiple alerts fire at once
- [ ] Tell me about a mistake you made and what you learned
- [ ] Why Blue Team instead of Red Team
